Sobre Mim

Sou Augusto De Souza Bertoli, Desenvolvedor Front-End Júnior focado em criar interfaces responsivas, acessíveis e de alta performance utilizando HTML, CSS e JavaScript, incluindo Fetch API, async/await, localStorage, CSS Grid, Flexbox e design responsivo. Também venho estudando React, aplicado no meu projeto mais recente.

Graduado em Análise e Desenvolvimento de Sistemas pela UNIP e atualmente cursando pós-graduação em Desenvolvimento Front-End pela Anhanguera. Possuo experiência prática no desenvolvimento de aplicações web modernas, com ênfase em organização de código e boas práticas de UI/UX.

Além do Front-End, tenho conhecimentos complementares em C, C#, Python e SQL. Busco aplicar meus conhecimentos técnicos para contribuir com soluções eficientes e evoluir em um ambiente profissional colaborativo.
